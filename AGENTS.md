# Agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) first. It is the source of truth, and this file only points at the parts agents most often get wrong.

- Branches are named `feature/`, `fix/` or `chore/` followed by a short description. Anything else is rejected.
- Work goes through a pull request against `main`. Never push to `main` and never merge your own pull request.
- Keep a change focused, add tests, and leave the build free of warnings.
- Line coverage must stay at or above 95%.
